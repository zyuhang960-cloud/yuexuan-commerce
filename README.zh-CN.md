# 悦选商城 · 全栈电商演示项目

一个可以本地运行的电商网站，用来演示完整的购物流程：浏览商品、注册登录、加入购物车、下单、查看订单，以及商家端管理商品和订单。项目由张宇航独立开发，用于课程之外的作品展示。

## 技术栈

- **后端**：Node.js 原生 `http` 模块，无框架；`node:sqlite` 直接操作 SQLite 数据库
- **数据库**：SQLite（`data/yuexuan.db`），首次启动自动建表并写入演示数据
- **前端**：原生 HTML / CSS / JavaScript，无构建步骤，浏览器直接打开
- **测试**：Node 内置 `node:test`，11 个接口级测试（注册、登录、购物车、下单、权限、库存、价格历史等）
- **部署**：提供 `Dockerfile`，可打包成容器运行

## 功能

**消费者端**
- 商品分类浏览、搜索、商品详情
- 注册 / 登录（密码强度校验），会员等级与积分
- 购物车增删改、下单、订单列表与状态
- 优惠券领取与使用、积分兑换
- 收货地址管理

**商家端**（账号 `merchant`）
- 商品上架、改价、改库存
- 订单查看与发货状态更新
- 数据看板（销量、库存提醒）

## 如何运行（对方电脑也能直接用）

1. 把整个「电商实习项目」文件夹复制过去，**不要只复制其中几个文件**。
2. 双击 **`启动悦选商城.bat`**。
3. 浏览器自动打开 <http://127.0.0.1:8787/>。

文件夹里已经带了 Node 运行环境（`runtime\node.exe`），对方电脑**不需要安装任何软件**。如果杀毒软件拦截 `node.exe`，允许一次即可。

也可以手动启动（需要本机装有 Node.js 22 以上）：

```bash
cd 商城程序
node server.js
```

商家账号：`merchant`　初始密码：`YueXuan@2026Admin`
（公开部署前请用环境变量 `YUEXUAN_ADMIN_PASSWORD` 改掉。）

## 演示数据

首次启动自带 228 件商品。想让商家看板里有订单，可在服务启动后执行：

```
cd 商城程序
..\runtime\node.exe tools\seed-demo.js
```

会生成 4 位顾客和 8 笔订单（重复执行会跳过已存在的手机号）。

## 目录结构

```
电商实习项目/
├─ 启动悦选商城.bat          # 双击启动，自动开浏览器
├─ 需求文档.md               # 项目需求与设计说明
├─ runtime/node.exe          # 随包携带的 Node 运行环境
└─ 商城程序/
   ├─ server.js              # 后端与接口（单文件）
   ├─ 网页前端/              # 页面、样式、前端脚本、商品数据与图片
   ├─ data/yuexuan.db        # SQLite 数据库
   ├─ tests/                 # 接口测试
   ├─ tools/seed-demo.js     # 生成演示订单
   └─ Dockerfile             # 容器化部署
```

## 我做了什么

- 全部后端接口与数据库设计（用户、商品、购物车、订单、优惠券、积分、地址）
- 前端页面与交互，包括商品列表、详情、购物车结算、个人中心、商家后台
- 权限隔离：消费者与商家的接口分开鉴权，防止越权操作
- 编写并跑通 11 个接口测试，修掉因商品数据扩充导致的测试失效
- 商品数据整理与图片资源本地化（不依赖外网图片），并把图片压缩到原体积约 1/12（49.6MB → 3.9MB），页面加载明显变快
- 补 404 错误页与站点图标，修掉手机端横向溢出
- 打包 Node 运行环境，做成一键启动，换电脑不用装软件
