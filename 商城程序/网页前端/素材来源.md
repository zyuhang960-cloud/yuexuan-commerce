# 素材来源

商城现有 156 件商品使用本地图片，商品名称、类别与图片按同一条商品记录对应。图片保存在 `assets/catalog/`，网页运行时不依赖外部图片服务器。新增的商超百货、餐具水具和烘焙厨具商品使用未在旧目录出现过的独立图片；自动测试会对全部图片做 SHA-256 去重并让 Edge 实际解码。
